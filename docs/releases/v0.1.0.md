# Serial Workbench v0.1.0

Serial Workbench 的首个独立版本：一个后台持有串口，你和 AI 通过网页、CLI、MCP 共用设备与日志。

## 本次发布

- 紧凑网页工作台：日志、终端、搜索、历史导出及自定义关键词配色。
- 后台持续采集，原始日志轮转落盘，各客户端按独立游标读取。
- 网页、CLI、MCP 共用快捷脚本，支持命令组、间隔、响应等待与版本检查。
- 协作记录显示具体命令、来源和状态，详情包含实际 TX/RX；记录重启后保留。
- 人工接管、共享发送队列及任务取消。
- 15 个 MCP 工具，JSON CLI；不要求 AI 必须通过 MCP 操作。
- 中英文 README、完整使用说明和 Windows 启动器。

## 下载

Windows x64：`serial-workbench-0.1.0-windows-x86_64.zip`。

解压后双击 `start-workbench.cmd`，打开本机网页；不需要 Rust 或 Node.js。也可以执行 `serial-workbench.exe serve`，再访问 `http://127.0.0.1:8765`。

包内包含共享工作台、兼容的 `serial-mcp-server.exe`、启动器、MIT 许可证、文档和文件校验清单；压缩包另附 SHA-256。未包含设备日志、脚本库或凭据。Linux/macOS 本次仅提供源码。

## 升级与兼容

- 保留 `workbench-data`，停止旧后台后再更换可执行文件。
- 旧浏览器快捷脚本首次打开时迁入共享后台，浏览器备份保留。
- 原项目 MIT 许可、署名与历史保留，来源为 Adancurusul/serial-mcp-server。
- 此版本属于 Serial Workbench 自己的版本系列。旧版直接串口入口继续兼容；宏 JSON 格式仍为 `schema_version: "0.3"`。
- 任务回包详情最多 64 KiB / 512 个事件，可能包含设备主动日志；完整内容可查会话历史。

## 验证

Rust 全部 79 项测试、Clippy、文档构建和工作台端到端冒烟检查通过。Windows PowerShell 5.1 / PowerShell 7 下验证了解压包启动、已有后台复用及版本。工作台此前已通过浏览器交互和真实 COM6/CH340 只读命令组验证；USB 拔插恢复与电气行为不在此次验证范围内。
